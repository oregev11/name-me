name-me

# idea
a website for choosing a baby name in hebrew.

the site will use ML with human in the loop for helping parents choose name for their baby.

# workflow
The site backend should have vectoric represenation of all available hebrew names (taken from some sources).
1. people enter few names they like.
2. the site will encode these names and find similar names using cosine similarity.
3. it will display grafically (using PCA) the entered names and the new suggested names.
4. user can now refine/change it search.
